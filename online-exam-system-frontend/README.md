# 智慧考试云平台 - 前端

本项目是智慧考试云平台的配套前端工程。采用 Vue + Vite + Element UI 构建，致力于提供极致的考试交互体验、高效的教学管理界面以及直观的数据化统计报表。

---

## 🌟 核心模块

### 📖 学习者中心 (学生端)
- **极速答题系统**：基于 Vue 响应式驱动的答题界面，支持多种题型，集成倒计时自动触发、切屏预警机制。
- **互动讨论区**：响应式的社交化学习模块，支持实时讨论、观点点赞与多级回复。
- **个人成长体系**：
    - **在线错题本**：支持错题分类查看、针对性重练。
    - **证书墙**：支持将考试成果在线生成为 PDF 或 图片格式证书，支持前端签名验证示例。
- **学习进度追踪**：可视化的考试记录与成绩趋势分析。

### 🏢 教学管理中心 (教师端)
- **智慧组卷工具**：
    - **可视化编辑器**：直观的试卷编排界面，支持拖拽排序（规划中）与分值实时计算。
    - **AI 辅助中心**：集成 AI 智能组卷入口，一键生成高质量试卷预览。
- **全方位题库中心**：支持 Latex 数学公式、图片等多媒体试题展示。
- **智能化阅卷**：支持客观题自动批改与主观题 AI 评分修正。
- **深度数据看板**：集成 ECharts，提供班级成绩分布、知识点掌握度等统计图表。

### ⚙️ 全局后勤中心 (管理员端)
- **组织架构管理**：层级化的用户、角色、班级管控体系。
- **全站审计**：基于图形界面的操作日志记录与异常数据监控。

---

## 🚀 技术栈

- **核心框架**：Vue
- **构建工具**：Vite(提供秒级的热更新体验)
- **UI 组件库**：Element UI
- **状态管理**：Vuex
- **路由系统**：Vue Router
- **网络通信**：Axios (集成通用拦截器与权限校验)
- **数据可视化**：ECharts
- **富文本引擎**：Quill + Image Resize/Drop 模块
- **文件与导出**：html2canvas + jsPDF (用于证书动态生成)

## 🛠️ 安装与开发

### 1. 环境准备
| 工具 | 版本要求 | 说明 |
| :--- | :--- | :--- |
| **Node.js** | >= 16.x | 建议使用 LTS 版本 |
| **Package Manager** | PNPM | 推荐使用 PNPM 以保证依赖一致性 |

### 2. 开始使用
1. **安装依赖**：
   ```bash
   pnpm install
   ```
2. **启动开发服务**：
   ```bash
   pnpm run dev
   ```
3. **项目构建**：
   ```bash
   pnpm run build
   ```

### **💡 快速说明**
- **权限控制**：系统采用动态路由加载方案，根据登录角色（admin/teacher/student）自动注入功能菜单。
- **开发建议**：如有接口变动，请在 `src/api` 下对应的模块文件中进行维护。
