# 智慧考试云平台项目亮点

本项目是一款功能全面、易于部署、界面美观的通用智慧考试云平台前端。基于 Vue.js 和 Element UI 构建，具有以下核心亮点：

## 1. 完善的多角色协同生态
系统深度适配学生、教师、管理员三类核心角色：
*   **学生端**：沉浸式考试体验，支持刷题中心、错题本、考试记录及证书获取。
*   **教师端**：便捷的试卷创建与分发，支持实时考情监控及在线阅卷。
*   **管理端**：全方位的资源管控，包括用户管理、班级体系及系统公告管理。

## 2. 严密的防作弊监控体系
内置高性能的防作弊技术方案：
*   **动态切屏检测**：利用浏览器的可见性 API（Visibility API）实时监控考生的切屏动作，并结合后端接口进行行为锁定。
*   **考试窗口锁定**：提供弹窗警示与自动退场机制，有效维护考场严肃性。

## 3. 全能的题目引擎支持
支持复杂多样的考试应用场景：
*   **题型覆盖**：完整支持单选题、多选题、判断题及主观简答题。
*   **图文混排**：题目内容及选项均支持图片上传与预览，适用于艺术、地理、医学等专业领域。
*   **答题卡联动**：提供可视化的侧边答题卡，支持未作答标记与一键题目定位。

## 4. 自动化与智能交互流程
提升操作效率与系统鲁棒性：
*   **自动交卷机制**：集成高精度倒计时组件，考试结束实时强制提交答案，防止超时。
*   **实时同步保存**：考生答题过程中答案自动异步保存至云端，无惧电源中断或网络卡顿。
*   **交卷摘要预览**：提交前自动统计各题型作答进度，提供未作答提醒。

## 5. 数字化成就驱动体系
显著增强用户反馈体验：
*   **PDF 证书生成**：集成 HTML2Canvas 与 JsPDF 技术，根据考生分数自动生成并下载精美的电子结业证书。
*   **可视化成绩分析**：通过直观的图表展示考生各科目的成绩分布与进阶曲线。

## 6. 企业级工程化标准
代码结构严谨，具备高度可扩展性：
*   **模块化代码结构**：严格遵循 Vue 最佳实践，组件拆分精细，便于二次开发。
*   **适配性强**：响应式设计完美适配不同分辨率的桌面终端。
*   **交互细腻**：全局加载动画、丝滑的切题过渡效果，提供流畅的用户体验。
