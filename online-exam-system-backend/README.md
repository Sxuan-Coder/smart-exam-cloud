# 智慧考试云平台 - 后端

> @author:上玄

本项目致力于打造一款功能完整、界面友好、部署简单的智慧考试云平台。采用 Spring Boot + MyBatis-Plus + Spring Security 的成熟架构，深度集成了 AI 智能化组卷与阅卷功能，支持多种复杂的考试与教学场景。

---

## 核心功能

### 学生端 - 沉浸式学习体验
- **在线考试**：流畅的答题界面，支持单选、多选、判断、简答等多种题型，集成自动倒计时、进度保存等功能。
- **智能化阅卷**：集成 AI 评分技术，客观题秒级判分，主观题支持 AI 给出评分建议及分析。
- **防作弊体系**：具备实时**切屏检测**与考试异常锁死机制，确保护考试过程的公平公正。
- **学习管理**：
    - **考试记录**：详尽的历史答题回顾，支持查看解析。
    - **智能错题本**：系统自动收集错题，助力知识点查漏补缺。
    - **证书中心**：成绩达标可自动生成精美的荣誉证书。
- **互动社区**：内置讨论模块，支持发布动态、回复评论及点赞互动。
- **系统通知**：全站公告/班级通知实时送达。

### 教师端 - 减负增效的教学神器
- **班级管理**：便捷创建班级，口令一键进班，全方位监控学生学习进度。
- **智慧题库管理**：
    - **分类体系**：支持多级题库分类，题集管理井井有条。
    - **多样化采题**：支持手动录入、Excel 批量导入、**AI 智能生成试题**。
- **考试全流程管理**：
    - **灵活组卷**：支持固定选题、随机抽题、**AI 智能一键组卷**（算法优化配比）。
    - **考场监控**：实时查看考生成绩分布、完成度等宏观指标。
- **深度成绩分析**：多维度的报表统计，支持成绩单批量导出。

### 管理员端 - 全局治理与监控
- **全权管理**：覆盖所有教师端功能。
- **用户体系管控**：精细化用户角色分配，支持用户数据、权限的集中式管理。
- **系统安全审计**：操作日志实时追溯，确保系统运行安全合规。

## 最近更新
- **AI 智能中枢**：引入 LangChain4j，支持基于知识点的 **AI 智能组卷** 与 **AI 自动判分**。
- **防作弊强化**：优化 WebSocket 实时连接机制，显著提升切屏检测的准确性。
- **证书水印防护**：生成证书支持签名校验逻辑，增强证书权威性。
- **交互优化**：全面升级讨论区交互逻辑，支持多级评论嵌套。

## 技术栈

### 后端核心
- **核心框架**：Spring Boot
- **持久层方案**：MyBatis-Plus + Druid 连接池
- **权限安全**：Spring Security + JWT (Json Web Token)
- **智能集成**：LangChain4j (OpenAI / Milvus)
- **文档架构**：Knife4j (OpenAPI 2 / Swagger)
- **工具引擎**：Hutool, Lombok, EasyExcel, ip2region

### 存储与中间件
- **数据库**：MySQL
- **缓存**：Redis
- **对象存储**：阿里云 OSS
